# SQE Gradebook

SQE Gradebook is a Python-based student grade management project developed for Software Quality Engineering (SQE) lab work. The project provides a structured foundation for managing students and their scores while following software engineering practices such as version control, testing, documentation, issue tracking, and continuous integration.
