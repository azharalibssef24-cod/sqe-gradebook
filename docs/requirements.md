# GradeBook Functional Requirements

## REQ-01 — Valid Score

The system shall allow a student to add a valid score from 0 to 100.

## REQ-02 — Negative Score Rejection

The system shall reject negative scores.

## REQ-03 — Non-Numeric Score Rejection

The system shall reject non-numeric score input.

## REQ-04 — Duplicate Student ID

The system shall reject the creation of a student when the student ID already exists.

## REQ-05 — Average Calculation

The system shall calculate the correct average when a student has one or more scores.

## REQ-06 — Empty Score Average

The system shall return 0.0 when the average is requested for a student with no scores.

## REQ-07 — Score Boundaries

The system shall accept the boundary scores 0 and 100.

## REQ-08 — Student Name Comparison

The system shall compare student names without treating uppercase and lowercase letters as different when name comparison is required.
